# Управление сайтом через Decap CMS

Админка находится по адресу `/admin/` и редактирует файл `content/site.json`.
Публичная страница сохраняет текущее HTML-содержимое как резерв и подставляет данные из JSON после загрузки.

## Что можно менять

- имя, слоган и описание;
- блок «Обо мне»;
- верхние чипы и навыки;
- интересы и их порядок;
- проекты, статусы, теги и ссылки;
- основной контакт и социальные сети.

## Локальная проверка

1. Установить Node.js.
2. В каталоге репозитория запустить `npx decap-server`.
3. Во втором терминале запустить локальный веб-сервер.
4. Открыть `http://localhost:PORT/admin/`.

`local_backend: true` разрешает локальной админке работать с репозиторием без OAuth.

## Публичный вход

GitHub требует OAuth-сервер для безопасного обмена кода авторизации на токен. Нельзя добавлять GitHub Client Secret или персональный токен в файлы сайта.

Перед публичным использованием нужно:

Самый простой вариант для этой конфигурации — использовать OAuth-службу Netlify, продолжая размещать основной сайт на GitHub Pages:

1. импортировать репозиторий `EnroXD1/myprofile` как новый проект Netlify;
2. добавить домен проекта вида `ИМЯ-ПРОЕКТА.netlify.app` в `backend.site_domain` файла `admin/config.yml`;
3. создать GitHub OAuth App с callback URL `https://api.netlify.com/auth/done`;
4. открыть в Netlify `Project configuration → Access & security → OAuth`;
5. установить провайдер GitHub и самостоятельно ввести Client ID и Client Secret.

Client Secret нельзя присылать в чат, добавлять в Git или помещать в JavaScript сайта.

После этого вход выполняется через GitHub, а кнопка Publish создаёт коммит в ветке `main`.
